👋 What Is LiliuxFlow?

LiliuxFlow is a program that turns your own computer into a private artificial intelligence server. Instead of sending your questions to a big company's website, LiliuxFlow runs the AI model right on your machine.

Think of it like this: most AI chatbots live in someone else's building. LiliuxFlow puts the whole building in your living room. Everything happens locally, on hardware you already own and control.

Under the hood, LiliuxFlow bundles three well-known pieces of software together and makes them work as one smooth package:

Lily The friendly layer that manages your models and keeps everything organised and running.
LiteLLM The translator that makes your local server speak the same language as popular AI services.
llama-swap The switchboard that swaps models in and out automatically so you never run out of memory.

Because all three are already wired together for you, you do not need to install anything separately, edit any configuration files, or understand what any of those names actually mean. You install one program, and it just works.

🧭 Your First Run

When LiliuxFlow opens for the first time, you will see a simple control screen. Here is what to expect and what to do.

  • A model list. LiliuxFlow shows the AI models available to you. On a first run, this list may contain one starter model that gets prepared automatically.
  • A status light. When the light or label says the server is running, you are ready to send requests. If it says it is starting, wait a short while and it will finish on its own.
  • A local address. LiliuxFlow gives you a short address that starts with http:// and points at your own computer. Any app that supports the OpenAI format can connect to that address, which means you can plug your private server into tools you already use.
  • Chat or test panel. Many builds include a small panel where you can type a message and watch the model reply, so you can confirm everything is working before connecting anything else.

If a reply appears in the test panel, congratulations — you now have your own private AI server running on your machine.

In normal use, LiliuxFlow is designed to stay out of your way. Open the program when you want your AI server available, and close it when you are finished. While it is open, any connected application can send requests to it, exactly as if it were a cloud service — only the answers come from your own machine.

Adding more models

LiliuxFlow can serve more than one model. When you add a new one, the managing layer takes care of loading it on demand and freeing memory when it is no longer needed. You do not need to plan which model to unload first — the software handles that decision for you.

Checking that everything is healthy

The control screen reports whether the server is running and which model is currently active. If something looks stuck, closing LiliuxFlow completely and opening it again resolves most temporary issues.

🛠️ Troubleshooting

The download will not start

Refresh the download page and try again. If your browser blocks the page, look for a small shield or warning icon near the address bar and choose to allow the download.

The program will not open

Restart your computer and try again. Security software occasionally needs a restart before it trusts a newly downloaded application for the first time.

The server says it is starting but never finishes

Large models take longer to prepare on the first run. Wait a few minutes. If it still has not finished, close the program fully and open it again.

Replies are slow

AI models are demanding on hardware. Smaller models respond much faster than larger ones. Choosing a smaller model in the model list is the quickest way to speed things up.

Something else is wrong

Visit the download page link below and use the repository's issue tracker to describe what you see. Include the exact message shown on screen — that helps enormously.

❓ Common Questions

Do I need to know how to code?

No. LiliuxFlow is built for people who want the benefits of a local AI server without writing any code. The setup is a download and a launch.

Is my data sent anywhere?

The models run locally, so your prompts and answers stay on your machine. LiliuxFlow is a self-hosted tool by design.

Do I need an internet connection?

You need a connection to download LiliuxFlow and to fetch new models. Once everything is in place, everyday use happens entirely on your computer.

Can other apps use my LiliuxFlow server?

Yes. The server is OpenAI-compatible, so tools that accept a custom server address can point at LiliuxFlow instead of an online service.

How do I remove it?

Uninstall it the same way you would remove any other program on your computer. Downloaded models can be deleted separately if you want to free up space.
